# Clara Netroom — contesto per l’assistente

## Cos’è
Clara Netroom è un **serious game browser** per la challenge **Consorzio Clara / Cisco Networking Academy**.
Obiettivo formativo: networking e cybersecurity in un’esperienza immersiva ma accessibile (web).

## Gameplay (visione, non ancora implementata)
- **Blue team**: giocatore in prima/terza persona in un **ufficio 3D low poly** (rack, scrivania, area SOC).
- **Red team**: per la prima fase **simulato** (script/bot/console), non un secondo giocatore umano obbligatorio.
- **Asset 3D**: da generare/importare con **Hyper3D Rodin** quando disponibili.

## Stack (vincolante)
- **Build**: Vite, TypeScript, porta dev/preview **5190** (`host: true`, `strictPort: true`).
- **Frontend**: React 19.
- **3D**: three, @react-three/fiber, @react-three/drei, @react-three/rapier.
- **Stato**: Zustand.
- **Multiplayer (futuro)**: colyseus, @colyseus/sdk.
- **Stile UI**: Tailwind v4 (`@tailwindcss/vite`), shadcn/ui (Radix, preset Nova), alias `@/*` → `./src/*` **senza** `baseUrl` in tsconfig.

## Convenzioni di lavoro
- Lavorare nella **root** del repo; non creare sottoprogetti annidati.
- **Non** introdurre gameplay o scope grosso senza richiesta esplicita; preferire incrementi piccoli e verificabili.
- README in **italiano** per documentazione di progetto.
- `npm run build` e `npm run lint` devono restare verdi (warning oxlint su `button.tsx` shadcn accettabile).
